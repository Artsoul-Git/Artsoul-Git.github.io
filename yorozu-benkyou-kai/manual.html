1. このLP群は何のためのもの？

ざっくり結論

岡山県よろず支援拠点が主催する 「Claude Code ミニセミナー」 と 「Claude Code 勉強会」 の毎回開催の告知用LP。テーマは毎回変わるが、企画の構造は共通なので「テーマ部分」だけ差し替えて使い回します。

📋 たとえると： 定型の通知文書テンプレートと同じ発想です。骨格（条件・流れ）は共通、当日のテーマ・日付だけ差し替えて使う。LPもタイトル・紹介文だけ毎回書き換えれば、すぐ次回告知に使えます。

4. 毎回の運用4ステップ

1
ABOUT 1 MIN
次回のテーマと対象LPを決める

「ミニセミナー」と「勉強会」のどちらに合わせたテーマか決めます。完成まで導きたい大きめのテーマ → ミニセミナー、コンパクトに1点突破 → 勉強会、を目安に。

💡 テーマ選定のコツ ・中小企業の業務に直結するテーマを優先
・「今日からできる」が訴求できる難易度に
・「自分の業務にも応用できる」要素を含める
2
ABOUT 3 MIN
テンプレ.mdに4要素を記入

同じフォルダにある yorozu-theme-template.md を開いて、該当LPの記入欄に4要素を書きます：

【対象LP】：yorozu-mini-seminar.html  または  yorozu-benkyou-kai.html
【開催日】：2026.8.30（土）
【タイトル】：（テーマの正式名）
【サブ】：（テーマの位置付け1行）
【紹介文】：（100〜200文字、何にチャレンジ／持ち帰り物）
💡 書き方のコツ テンプレ.md内に「書くときのコツ」セクションがあるので、迷ったらそこを参照してください。
ミニセミナーと勉強会で適したテーマの違いも記載してあります。
3
ABOUT 1 MIN
Claudeに差し替えを依頼

テンプレ.mdの「Claudeへの差し替え指示プロンプト」をコピーして、Claude Code に貼り付け。Enter で実行。

Claudeが自動で：

  • テーマセクションの4要素を新しいものに置き換え
  • meta description / og:description を更新
  • 差し替え完了報告
💡 確認方法 ブラウザで該当LPを開いて、テーマセクションが新しい内容になっているか確認。
4
ABOUT 1 MIN
告知開始

LPのURLをよろず支援拠点の予約フォーム・メール案内・各種媒体で告知。OGP（SNSシェア時のサムネ）も新テーマの紹介文に切り替わっています。

⚠️ 注意 公開URLを変える場合は別途 git push が必要です。公開系操作は明示承認後に実行のルール。

5. 差し替えるパーツの場所

HTMLでの差し替え位置を見る ▾

テーマセクションは id="theme" で識別。差し替え対象はコメントで明示しています（両LP共通構造）：

<section class="today-theme" id="theme">
  ...
  <div class="theme-card fade-up">
    <!-- ▼▼▼ 差し替え区間 START（テーマ変更時はここから） ▼▼▼ -->
    <div class="theme-vol">開催日：2026.6.27（土）</div>
    <h2 class="theme-title">実践Claude Code！...</h2>
    <p class="theme-sub">AIと一緒に育てる、あなたの看板の作り方</p>
    <div class="theme-desc-box">
      <p>Claudeデスクトップアプリで気楽に...</p>
    </div>
    <!-- ▲▲▲ 差し替え区間 END（テーマ変更時はここまで） ▲▲▲ -->
  </div>
</section>

この「▼▼▼ START」から「▲▲▲ END」の間だけが差し替え対象です。

meta タグの差し替え位置を見る ▾

HTML冒頭の <head> 内：

<meta name="description" content="（紹介文がここに入る）">
<meta property="og:description" content="（同じ内容）">

テーマ差し替え時、Claudeがこれも一緒に更新してくれます。

6. その他のカスタマイズ（オプション）

会場情報・予約フォームURLを入れたい時 ▾

ヒーローの .hero-meta 内、または「今回のテーマ」カード下に新しいセクションを追加することで対応可能。Claudeに「会場情報セクションを追加して」と依頼してください。

勉強会のシリーズイメージ（EPISODE）を更新したい時 ▾

勉強会LPの .series-grid 内、4つの .series-box の中身を書き換え。Claudeに「シリーズイメージのEPISODE 01〜04を以下に変更して：…」と依頼。

個別相談の曜日・URLを変えたい時 ▾

本文中「毎週水曜」記載と、FAQ「個別相談はどう申し込む？」の回答内のURL／予約方法を一括書き換え。Claudeに「個別相談の曜日を◯曜に変更し、関連箇所をすべて更新して」と依頼。

⚠️ うまく動かない時はここを開く ▾
症状対処
差し替え後にデザインが崩れたHTML タグ（<h2>等）を消してしまった可能性。git で1つ前に戻して再実行。
「開催日」だけ反映されないテンプレ.mdの【開催日】欄に書いていない可能性。記入してから再実行。
meta description が更新されていないClaudeへの指示プロンプトに「meta description も更新して」が含まれているか確認。
ブラウザで古い内容が表示されるブラウザのスーパーリロード（Ctrl+Shift+R）。
違うLPに反映されてしまった指示プロンプトの【対象LP】を確認。yorozu-mini-seminar.html と yorozu-benkyou-kai.html は別物。

7. 用語集（気になる人だけ）

LP（ランディングページ）
告知や申込誘導のための1ページ完結型ウェブページ。
テーマセクション
このLP内で毎回差し替える「今回のテーマ」部分。id="theme" で識別。
差し替え区間
HTMLコメント「▼▼▼ START」と「▲▲▲ END」で囲まれた、テーマ差し替え対象範囲。
SPECIAL／フォローアップ
「手順書配布 → 持ち帰り実践 → 水曜個別相談」のフォロー導線セクション。両LPで共通の核要素。
開催日表記
「開催日：YYYY.M.D（曜日）」形式で記載。例：「開催日：2026.6.27（土）」。
meta description
検索エンジンや SNS でURLを共有した時に表示される説明文。SEO的にも重要。
OGP
「Open Graph Protocol」。SNS シェア時のサムネとタイトルを設定する仕組み。og:title や og:description で指定。
OGP デバッガー
Facebook や X が提供する、OGP キャッシュの確認・更新用ツール。シェア時に古い情報が出る時に使う。
