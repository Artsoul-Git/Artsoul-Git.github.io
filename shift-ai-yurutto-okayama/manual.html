0. このLPは何のためのもの？

ざっくり結論

「ゆるっと作業会」の 毎回開催の告知用LP。テーマは毎回変わるが、企画の構造は共通。
→ 「テーマ部分」だけ差し替えて使い回す設計です。

📋 たとえると： 定型契約書のテンプレートと同じ発想です。骨格（条文・条件）は共通、当事者名・金額だけ差し替えて使う。LPもタイトル・紹介文だけ毎回書き換えれば、すぐ次回告知に使えます。

2. 毎回の運用4ステップ

1
ABOUT 1 MIN
次回のテーマを決める

主催者2人で、次回のテーマを決めます。「Claude Code 入門」「LP作成」「議事録整形スキル」など、3時間で完結できる規模で。

💡 テーマ選定のコツ ・ビジュアル系（LP・名刺・スライド）とビジネス系（議事録・メール返信・スキル作成）を交互に
・初心者でも完成体験が得られる難易度に
・「自分の業務にも応用できる」要素を含める
2
ABOUT 3 MIN
テンプレ.mdに4要素を記入

同じフォルダにある yurutto-theme-template.md を開いて、「次回テーマの記入欄」に4要素を書きます：

【開催日】：2026.8.30（土）
【タイトル】：（テーマの正式名）
【サブ】：（テーマの位置付け1行）
【紹介文】：（100〜200文字、何にチャレンジ／持ち帰り物）
💡 書き方のコツ テンプレ.md内に「書くときのコツ」セクションがあるので、迷ったらそこを参照してください。
3
ABOUT 1 MIN
Claudeに差し替えを依頼

テンプレ.mdの「Claudeへの差し替え指示プロンプト」をコピーして、Claude Code に貼り付け。Enter で実行。

Claudeが自動で：

  • テーマセクションの4要素を新しいものに置き換え
  • meta description / og:description を更新
  • 差し替え完了報告
💡 確認方法 ブラウザで shift-ai-yurutto-okayama.html を開いて、テーマセクションが新しい内容になっているか確認。
4
ABOUT 1 MIN
告知開始

LPのURLをDiscord 等で共有して告知開始。OGP（SNSシェア時のサムネ）も新テーマの紹介文に切り替わっています。

⚠️ 注意 公開URLを変える場合は別途 git push が必要です。公開系操作は Kei 明示承認後に実行のルール（CLAUDE.md準拠）。

3. 差し替えるパーツの場所

HTMLでの差し替え位置を見る ▾

テーマセクションは id="theme" で識別。差し替え対象はコメントで明示しています：

<section class="today-theme" id="theme">
  ...
  <div class="theme-card fade-up">
    <!-- ▼▼▼ 差し替え区間 START（テーマ変更時はここから） ▼▼▼ -->
    <div class="theme-vol">開催日：2026.6.27（土）</div>
    <h2 class="theme-title">実践Claude Code！...</h2>
    <p class="theme-sub">AIと一緒に育てる、あなたの看板の作り方</p>
    <div class="theme-desc-box">
      <p>Claudeデスクトップアプリで気楽に...</p>
    </div>
    <!-- ▲▲▲ 差し替え区間 END（テーマ変更時はここまで） ▲▲▲ -->
  </div>
</section>

この「▼▼▼ START」から「▲▲▲ END」の間だけが差し替え対象です。

meta タグの差し替え位置を見る ▾

HTML冒頭の <head> 内：

<meta name="description" content="（紹介文がここに入る）">
<meta property="og:description" content="（同じ内容）">

テーマ差し替え時、Claudeがこれも一緒に更新してくれます。

4. その他のカスタマイズ（オプション）

必要に応じて以下も変更できますが、頻繁に変える必要はありません。

会場情報・開催日時を入れたい時 ▾

ヒーローの .hero-meta セクション内、または「今回のテーマ」カード下に新しいセクションを追加することで対応可能。Claudeに「会場情報セクションを追加して」と依頼してください。

主催者の名前・写真を入れたい時 ▾

「あなたを迎える2人」セクションの .team-card 内、avatar の文字（「企」「支」）や h4 を書き換えます。写真を入れる場合は、画像ファイルを同フォルダに置いて img タグで参照。

申込URLを追加したい時 ▾

現在は「内容を見る」と「今回のテーマ」の2ボタンのみ。申込URL（例：Peatix / connpass）を追加する場合は、ヒーローCTAに3つ目のボタンを追加するか、別途バナーを差し込みます。Claudeに依頼可能。

※ 公開URL追加は Kei 明示承認後 に進めます。

⚠️ うまく動かない時はここを開く ▾
症状対処
差し替え後にデザインが崩れたHTML タグ（<h2>等）を消してしまった可能性。git で1つ前に戻して再実行。
「VOL.XX」だけ反映されないテンプレ.mdの【Vol／月】欄に書いていない可能性。記入してから再実行。
meta description が更新されていないClaudeへの指示プロンプトに「meta description も更新して」が含まれているか確認。
ブラウザで古い内容が表示されるブラウザのスーパーリロード（Ctrl+Shift+R）。
OGP（SNSシェア時のサムネ）が古いFB／X のシェアデバッガーでキャッシュクリア依頼。

5. 用語集（気になる人だけ）

LP（ランディングページ）
告知や申込誘導のための1ページ完結型ウェブページ。
テーマセクション
このLP内で毎回差し替える「今回のテーマ」部分。id="theme" で識別。
差し替え区間
HTMLコメント「▼▼▼ START」と「▲▲▲ END」で囲まれた、テーマ差し替え対象範囲。
開催日表記
「開催日：YYYY.M.D（曜日）」形式で記載。例：「開催日：2026.6.27（土）」。テンプレ.md記入時もこの形で。
meta description
検索エンジンや SNS でURLを共有した時に表示される説明文。SEO的にも重要。
OGP
「Open Graph Protocol」。SNS シェア時のサムネとタイトルを設定する仕組み。og:title や og:description で指定。
OGP デバッガー
Facebook や X が提供する、OGP キャッシュの確認・更新用ツール。シェア時に古い情報が出る時に使う。
